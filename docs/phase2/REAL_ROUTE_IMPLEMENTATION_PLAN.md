# Phase 2B-1 구현 계획

목표: 기존 DEMO를 보존하고 출처가 있는 장소와 자동차 경로 계약을 분리해 검증한다. 사용자 Phase 2B-1 명세를 기준으로 현재 작업 트리에서 순서대로 수행한다. 커밋·Push하지 않는다.

구조: `realdata`에 좌표·장소·위치·경로 계약, 공식 JSON 파서와 경로 기반 평가기를 둔다. 기존 DestinationEngine은 수정하지 않고 검증된 시간 제약을 통과한 후보의 선호 점수 계산에 재사용한다. 별도 내부 Activity는 실제 장소/미구성 실경로/명시적 Mock을 구분한다. API 인증키를 APK에 넣지 않는다.

- [x] 장소·경로 파싱, 오류, 왕복, 예산, 공개 전 비밀 유지 테스트를 먼저 작성하고 실패 확인.
- [x] 서울 공개 장소 5개와 출처·UNKNOWN 필드, LocationProvider 및 경로 응답 계약 구현.
- [x] 별도 경로 평가기 구현. 편도/복귀 각각 조회, 체류·여유 포함, Mock 출처 유지.
- [x] 정차 UX 제한을 재사용하는 검증 화면 연결. 기존 DEMO 저장 형식·SDK·PoC 보존.
- [x] 표준 빌드와 전체 회귀 테스트, Pleos 설치/화면/로그 검증.
- [x] 실제 호출 불가와 정책 미확인을 구분하여 결과 문서 및 변경사항 검토.

검토 중점: 초/분 경계·합산 오버플로, 왕복 한쪽 실패, 미확인 차량 거리, 잘못된 좌표/응답, 공개 전 이름·좌표 유출, 화면 재생성 시 임시 데이터 손실. 실제 GPS는 일반 권한 절차만 사용하며 위치를 영구 저장하지 않는다.

완료 기록: 기존58 + 신규20 = 78개 테스트 통과. 독립 읽기 전용 검토에서 발견된 초 단위 합계/구간별 올림 불일치와 숨은 귀가 마감 문제를 수정하고 회귀 테스트 추가. 정상 시스템 권한 절차로 전경 위치 접근을 확인했으며 위치/경로 데이터는 저장하지 않음. 실제 경로 호출과 proxy는 키 부재로 미검증. 최종 결과는 REAL_ROUTE_DATA_VALIDATION.md 참조.
