# Phase 2A Core Experience Implementation Plan

> 실행: executing-plans 방식으로 현재 프로젝트 루트에서 진행. 사용자 요청에 따라 커밋·Push 없이 기존 파일을 보존한다.

**Goal:** 정차용 DEMO 전체 흐름과 재사용 가능한 규칙 기반 추천/상태 모델 구현.

**Architecture:** 기존 MainActivity의 진단 기능을 유지하고 ExperienceActivity로 진입한다. Android에 의존하지 않는 모델·엔진·컨트롤러/스냅샷 codec, 작은 Android 저장/UX 제한 어댑터, 선택형 View UI로 분리한다. 기존 SDK·nav-host-poc를 통합하거나 실제 안내를 시작하지 않는다.

**Tech Stack:** 기존 Kotlin/Views/AppCompat/JUnit, 공식 android.car UX 제한 API. 신규 외부 서비스/키/의존성 버전 변경 없음.

## 설계 선택과 제약

- MainActivity 전면 교체와 PoC 통합 대신 별도 내부 Activity로 분리한다. 시작 화면과 SDK 진단 재검증을 보존하기 위해서다.
- 장소는 명시적인 가상 샘플, 좌표 없음. 시간은 합성 시나리오 값이며 실제 경로/영업/주차 검증으로 표시하지 않는다.
- 사용자가 선택한 기분/범위/장소/동반자/시간 또는 귀가 시각/복귀/랜덤을 도메인 모델에 저장한다. 날씨/계절/차량 주행 가능 거리는 확인된 값만 사용한다.
- 시간·귀가·장소·동반자·최근 기록·실제 확보된 거리 제약을 먼저 적용하고, 기분/선호/환경 점수와 제한된 seeded randomness로 순위를 정한다.
- 준비/DEMO의 공개용 모델에는 목적지 이름/좌표를 넣지 않는다. 즉시 공개와 도착 모의 후 공개는 별도 이벤트다.
- SETUP→PLANNING→READY→DEMO_DRIVING→ARRIVED→REVEALED→COMPLETED. 수정/취소/실패/데이터 없음은 준비 상태로 복귀하고 실제 경로 호출은 없다.
- 단순한 로컬 암호화 저장으로 선택·코스·DEMO 기록을 복원한다. 실제 방문/지도와 혼동하지 않으며 Git/백업에 사용자 데이터를 넣지 않는다.
- CarUxRestrictions 불명/제한 상태에서는 입력을 막는다. DO 선언으로 제한을 우회하지 않는다. 실제 주행 UI는 이번 범위가 아니다.
- 다크 그린 배경/라임 강조, 큰 터치 영역, 정적 코스 도식, 세 단계 선택 폼/조건 요약, 이름 공개/만족도/기분 기록. 풍경 사진·과도한 애니메이션 없음.

## 실행 작업

- [x] 도메인 테스트를 먼저 추가하고 실패를 확인한다: 필터/기분/시간/귀가/데이터 부족/차량 불명/비공개/도착/취소/복원/중복 기록.
- [x] `experience/core/` 모델, 샘플 catalog, DestinationEngine, TripController, snapshot codec 구현 후 테스트 통과.
- [x] `experience/`의 ExperienceActivity, 정차 UX 어댑터, 암호화 저장 및 정적 도식 View 구현. 기존 화면에는 진입 버튼만 추가.
- [x] 표준 빌드/기존 28개 회귀/새 테스트, ADB 설치/시작, 각 주요 화면·오류/재시작 검증.
- [x] 검증 문서·캡처·수치 기록, 기존 SDK/PoC/빌드 환경 diff 확인 및 읽기 전용 코드 검토.

## 중점 검토

- 오래된 귀가 시각/합성 시간과 실제 길 안내의 혼동을 막을 것.
- 상태 복원 중 후보가 없거나 저장이 손상돼도 목적지를 미리 노출하거나 기록을 덮어쓰지 않을 것.
- 방문 기록/만족도는 DEMO로 표시하고 완료 이벤트를 중복 기록하지 않을 것.
- 주행 제한/서비스 끊김/화면 재개 시 정책 상태를 새로 확인할 것.
- 창 크기에 맞게 스크롤과 버튼을 유지하고 UI에서 실명·좌표가 공개 전에 새지 않을 것.


## 검증 메모

- 도메인 RED → GREEN, 독립 검토의 확인창 정책 경합 보완, 단위 미확인 RANGE 차단.
- Pleos는 android.car를 부팅 경로로 제공하므로 선택적 library 선언을 사용했다. 실제 API 미확인 때 잠금 유지.
- 주요 화면·실패·취소·즉시 공개·도착·기록/진행 복원을 ADB로 확인했다. 최종 수치는 CORE_EXPERIENCE_MVP.md 참조.
- 모든 작업은 사용자 지정 루트 내에서 수행했다. 커밋/Push 없음.
