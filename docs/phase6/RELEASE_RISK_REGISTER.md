# SURPRIDE Phase 6A — 제출·배포 위험 등록부

2026-11-10 · **AUDIT_WITH_LIMITATIONS**

이 문서는 코드 감사 완료와 제품 출시 허용을 구분한다. 현재 허용 가능한 범위는 기존 제한을 유지한 정차 개발 AVD 검증이다. 이번에는 앱·내비게이션·서버를 시작하거나 기기를 조작하지 않았다. 실차·공개 서버·상용 배포 준비 완료 판정이 아니다.

코드 감사 집계는 **P0 0 / P1 5 / P2 9 / P3 2 = 16건**이다. 아래 R01–R14는 그 항목과 기존 Phase 제약을 묶은 release gate이며 새 발견으로 중복 집계하지 않는다. P0 0건은 잠재적인 잘못된 안내·위치 노출 위험이 없다는 뜻이 아니다. 현재 정차/에뮬레이터 제한을 전제로 분류했으며, 이를 해제하면 A01/A02를 포함해 P0 여부를 다시 평가해야 한다. 사고가 발생해야 P0로 분류하는 기준은 아니다.

## 4. 테스트·실행 근거의 한계

- 이번 482개 재실행은 JVM/Mock transport/공식 testing API 검증이다. actual Pleos Focus·GPS·마이크·스피커·Host E2E를 482개 실행한 것이 아니다.
- 계측 10개와 실제 앱/PoC 실행 성공은 5C 근거를 승계한다. 이번에는 연결된 기기 목록 조회·앱 설치·계측·GPS 입력·경로 시작을 하지 않았다.
- 5C 복귀는 중첩 구간에서 중단 후 현재 위치 경로 재요청으로 마지막 접근을 완료했다. 원래 왕복 전체의 연속 성공은 미검증이다.
- 3B-4 soak는 고정 공개 위치 500회/632.6초. PSS 두 표본은 약 6.53MiB 증가했다. 누수 증명이나 수시간 안정성 증명은 아니다.
- 실제 경관 후보 0곳, waypoint LIVE CLOSED, STT PARTIAL, route quality PARTIAL, visual approval pending을 회귀 통과로 해제할 수 없다.

## 6. 제출 전 반드시 해결할 문제

**정차 공모전 데모:** A01/A02, A03/A06, A04/A05를 우선 해결·검증하고 A07을 수정한다. 전체 P1은 완료 증거 또는 Host 외부 제한에 대한 명시적인 시연 차단·지원 범위 결정을 남긴다. 평가·복귀 시나리오가 process recreation·네트워크 실패에서 정직한 오류/재준비로 이어져야 한다. A11의 보존 정책과 공개 자료 검토를 끝낸다. 미해결 상태에서 완전 비공개·실차 길 안내·STT 성공·검증 경관 추천이라고 발표하지 않는다.

**소스/증거 공개:** 알려진 키 literal/패턴 0건 결과만으로 승인하지 않는다. 기존 미커밋 증거와 PNG·문서·APK 포함 여부를 직접 검토하고 민감 위치·대화·인증정보가 없는지 확인한다. `.gitignore`는 이미 존재하는 원격 사본이나 이미지 내용의 보안을 보증하지 않는다. 키가 발견되면 원문 공개 없이 회전/폐기·노출 범위를 별도 처리하고 이력 변경은 사용자 요청 없이 수행하지 않는다.

**실차·상용 서비스:** R01–R14의 해당 게이트 해제, 제공업체/플랫폼 승인과 실제 안전성·운영 검증이 필요하다. 개발용 단기 프록시와 두 APK의 현재 구조를 그대로 운영 배포하는 계획은 없다.

## 7. Phase 6B 진입 조건

1. 감사 기준 HEAD·기존 변경·667개 보존 파일 해시를 고정한다. 이 상태를 clean 또는 커밋된 상태로 잘못 보고하지 않는다.
2. [개선 계획](REFACTOR_PLAN.md)의 B1부터 작은 수정 범위를 확정한다. 확정된 합성 재현 3개를 정식 회귀로 옮기고 기존 테스트는 유지한다.
3. 현재 정차/에뮬레이터/명시적 시작/출처/권한/소유권/waypoint CLOSED 제한을 유지한다. 안전 완화를 통한 시연 성공은 완료로 인정하지 않는다.
4. 실제 Host 검증이 필요한 A04/A05는 코드 테스트와 다른 완료 증거로 관리한다. 실행하지 못한 조합은 UNVERIFIED로 남긴다.
5. 코드 변경·기기 실행·배포·커밋/Push는 이번 감사 산출물 작성과 분리한다. Phase 6A 완료가 이러한 작업의 자동 실행 지시는 아니다.

**현재 결정:** 분석 자료가 충분하므로 **제한을 유지한 Phase 6B 개선 작업에 진입 가능**하다. 실제 시스템·성능·실차 검증이 남아 최종 감사는 **AUDIT_WITH_LIMITATIONS**다. 소스/테스트 수정·기기 조작·서비스 배포·커밋/Push는 이번에 수행하지 않았다.

미확인: 실제 Host 재검증·실차·음향·장시간 부하·전체 개인정보 채널·최신 취약점/공급자 승인. 잔여 위험은 테스트 개수로 상쇄되지 않으며 해당 게이트의 직접 증거가 필요하다.
