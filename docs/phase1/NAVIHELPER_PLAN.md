기존 main / HEAD 1f485f4f154b33647216b5af23155d4eb3486ee4, 시작 시 clean. 커밋·Push 없이 다음 범위로 진행한다.

- 단위 테스트 → 빌드 → 연결/기존 경로 확인 → 명시적 경로 실험 → OEM 화면/홈 등 관찰 → 안전한 취소 순서로 검증한다. 미확인 채널을 비공개 성공으로 간주하지 않는다.
