# SURPRIDE 예선용 110초 소개 편집본

**영상 준비도: READY_WITH_LIMITATIONS.** 로컬 [MP4](assets/SURPRIDE_preliminary_prototype_110s.mp4)와 [SRT](assets/SURPRIDE_preliminary_prototype_110s.srt)를 준비했다. 1920×1080, H.264/YUV420p, 20fps, **110초**, 무음·자막 방식이다. 90~120초는 이번 내부 제작 목표이며 공식 제한 시간으로 주장하지 않는다.

기존 앱 검증 캡처의 **앱 영역만 발췌**하고 설명·자막을 더했다. 새 실행 녹화, 버튼 조작 애니메이션, 실제 연속 주행 영상은 아니다. 입력 조건·테마가 다른 개별 실행을 편집했으므로 한 세션의 추천→주행→도착 완주로 해석하면 안 된다. 캡처 안의 앱 화면 픽셀을 조작하거나 가짜 활성 컨트롤을 합성하지 않았다. 실제 TTS 음향도 넣지 않았다.

## 자막 원고

1. SURPRIDE는 기분과 시간으로 시작하는 차량용 드라이브 경험입니다.
2. 나에게 맞는 기분과 시간을 고르고, 돌아올 시간까지 함께 생각합니다.
3. 자연어로 적은 요청을 조건으로 정리합니다. 자유 대화형 LLM은 아닙니다.
4. 해석된 조건을 확인하고 고칩니다. 실제 경관도로 검증은 앞으로의 과제입니다.
5. 도로와 목적지를 함께 평가한 비밀 코스입니다. 시스템 전체 비공개를 보증하지 않습니다.
6. 지도·GPS·안내 연동은 구현했습니다. 현재 Host ACTIVE는 BLOCKED입니다.
7. DEMO에서는 도착 후 공개와 평가 흐름을 체험합니다. 실차 방문 증거는 아닙니다.
8. 기분별 기록과 재방문 경험으로 확장합니다. 현재 기분 지도는 DEMO 개념도입니다.
9. 정차 프로토타입을 바탕으로 Host·음성·경관 검증을 보완합니다. 시청해 주셔서 감사합니다.

## 제작·검토 결과

- 공식 안내에서 목업·프로토타입·화면 녹화를 인정하므로, 실제 증거와 구조 설명을 구분한 편집 방식을 선택했다. [공식 모집 공고](https://appdevchallenge.auto-hmg.io/notice/c0a1a000-2026-4923-8000-000000000001).
- 실제 앱/PoC/AVD를 실행·설치하거나 GPS를 변경하지 않았다. ACTIVE 차단을 우회하지 않았다. 영상 60–74초에는 활성 Host 화면을 넣지 않았다.
- 7개의 고유 후보 캡처를 contact sheet로 확인하고 사용한 6개 고유 원본의 앱 영역을 검토했다. 참여자 연락처·서명·토큰·원시 좌표를 새 영상에 넣지 않았다. 문장·장소 표시는 개발용 예시/가상 장소다. 저장소 전체300개 PNG의 OCR 완료를 의미하지 않는다.
- 전체9개 제작 프레임과 주요 장면의 원본 크기 렌더를 확인했다. 최종 MP4 길이/codec/해상도·무음 stream과 실제 인코딩 프레임도 검증한다. 마감 전 최종 시청·최종 문구 승인·업로드된 링크 재생 확인은 사람이 수행해야 한다.
- 음원·새 실음성·차량 주행 음향은 없으며, 무음 설명 편집본이다. 내레이션이 필요하면 위 원고를 별도 녹음하되 실제 TTS 성공 증거처럼 표시하지 않는다.

## 제출 전 선택

로컬 파일은 준비됐지만 외부 영상 URL은 아직 없다. 검토 후 운영 안내에 맞는 첨부 또는 접근 가능한 영상 링크를 선택하고, 공식 양식 참고자료 칸에 **“정차 프로토타입 검증 캡처 편집본, 110초”**라고 적는다. 실제 연속 주행·최신 ACTIVE E2E·실차 안전성 검증 영상이라는 제목은 사용하지 않는다. 숏폼 특별상용 세로 영상과는 별개다.
