# 2026 HMG 예선 제출 체크리스트

2026-11-11 확인. 이 문서는 **제출 준비용**이며 작성·서명한 공식 접수양식을 대신하지 않는다. 기획서부터 완성하고 선택 자료 때문에 필수 접수를 놓치지 않는 것을 권고한다. 이메일 발송·GitHub 권한 변경은 하지 않았다.

## 공식 요건

| 확인할 항목 | 접수 전 확인 |
|---|---|
| 필수 양식 | 공식 DOCX의 신청서·작품 소개·동의/서명 부분 작성. 접수양식 자체가 기획서 |
| 날짜 | 홈페이지는11월15일 마감, 내려받은 공식 양식은 **2026-11-15 23:59**까지 기재. 모든 일정은 KST. 발송 당일 공지 재확인 |
| 참가자 | 대표 포함 최대5인. 각자 동의 여부·서명·날짜 기재. 팀원 전원 CC |
| 발송 | `appdevchallenge@hyundai-partners.com`, 제목 `[차량용 앱 개발 공모전] 팀명(개인은 성명)_대표자명` |
| 수정 | 마감 전 같은 발신자로 전체 자료·서명 동의서를 재첨부, 전원 CC. 제목에 `[수정제출]` 추가, 마지막 접수본 기준 |
| 선택 자료 | 목업/프로토타입/녹화 영상과 소스+APK GitHub가 단계별 가산점. 숏폼은 별도 특별상·본상 가산점 없음 |

출처: [공식 제출 안내](https://appdevchallenge.auto-hmg.io/guide/submission), [공식 빈 양식 DOCX](https://appdevchallenge.auto-hmg.io/downloads/contest-application-consent.docx), [FAQ](https://appdevchallenge.auto-hmg.io/faq). 양식은 이번에 다운로드해 본문 구조·마감 시각을 확인했으며 개인정보를 채워 공개 파일로 만들지 않았다.

## 사람의 최종 작성·확인이 필요한 항목

- [ ] 참가 부문·팀 구성·역할 확정. 팀명/대표자/연락처는 저장소 밖의 공식 원본에만 작성.
- [ ] 공식 양식 02 작품 소개에 [본문 제안](PROPOSAL_IMPLEMENTATION_REVIEW.md)을 검토해 반영. 대표자·팀원 실명·연락처·소속은 작품 소개에서 제외.
- [ ] 공식 양식 01 운영 연락정보와 03·04 동의/서명/날짜를 참가자 전원이 작성. CC는 개별 서명의 대체가 아님.
- [ ] 실제로 없는 영상/GitHub Release 링크를 양식에 넣지 않음. 선택하지 않은 자료는 미제출로 표시.
- [ ] 첨부 파일 열림·폰트·누락·링크 접근을 다른 환경에서 확인. 원본/최종 파일 해시와 수정 버전을 개인 보관.
- [ ] 받는 주소·제목·팀원 CC·전원 동의서·전체 첨부물을 발송자가 확인하고 직접 제출. 접수 확인은 운영 안내에 따라 확인.

필수 작성 양식/동의서가 아직 저장소 안에 없으므로 **실제 접수 패키지는 NOT_READY**다. 이 프로젝트에서는 작성 완료 여부·서명을 추정하지 않는다.

## GitHub·APK를 선택할 때

공식 안내는 소스와 실행 가능한 Release APK를 함께 제출하고 `apk/` 폴더 또는 용량 초과 시 GitHub Releases를 사용하도록 한다. 파일명은 `팀명_앱이름_release.apk` 형식이다. Private도 허용하되 공식 심사용 계정 초대·접근 확인과 개인 계정의 쓰기 권한 영향을 확인해야 한다. [GitHub 제출 안내](https://appdevchallenge.auto-hmg.io/guide/submission).

이번 확인에서 공식 본문·FAQ·공지에 **심사용 계정의 구체적 login을 찾지 못했다**. 추측해 초대하지 말고 운영 측의 공식 안내로 확인한다. 현재 저장소는 이미 Public이므로 그 확인은 Private 제출로 바꿀 때의 조건이다. Public/Private 변경·초대는 하지 않았다. 현재 Release 보류 사유는 [별도 보고서](GITHUB_RELEASE_READINESS.md)에 있다.

## PT까지의 일정

1차 결과는11월23일, PT는12월3~4일이다. PT 전 실제 동작 앱과 최종 개발 결과물이 필요하며 예선 이후 고도화가 허용된다. 정확한 PT 제출 기한/세부 기준은 후속 공지를 확인한다. 2027년2월 전시 준비를 개발 완료 기한으로 미루지 않는다. [일정](https://appdevchallenge.auto-hmg.io/guide/schedule), [심사 안내](https://appdevchallenge.auto-hmg.io/guide/judging-awards).

권고 일정은 공식 규정과 구분한다: **11월13일까지 서명본·기획서 확정 → 14일까지 영상/링크와 첨부 검사 → 15일 여유 있게 직접 발송**. APK가 준비되지 않으면 필수 기획서와 검토한 영상으로 우선 접수한다.
